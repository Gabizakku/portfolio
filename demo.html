Ask the co-op

An assistant that answers only from what this site actually says.

Hello. Ask me about workshops, membership, the harvest table or how to get here.

No model call and no guessing. The answers below are matched against a fixed set of facts the site owner controls, so the assistant cannot invent a price or promise a date that does not exist.

A production version would swap this for a retrieval step over the owner's own pages, with the same rule: if the answer is not in the source, say so and hand over to a person.
